Multi-language support with i18next, 5 languages (FR priority, EN, ES, DE, AR with RTL)

## Setup
- i18next + react-i18next + i18next-browser-languagedetector
- Config: `src/i18n/index.ts`
- Translations: `src/i18n/locales/{fr,en,es,de,ar}.json`
- Init in `src/main.tsx`
- Auto-detection: localStorage > navigator > htmlTag
- Fallback: French (fr)

## Components
- `src/components/LanguageSelector.tsx` — dropdown with flags
- Added to PublicLayout header (desktop + mobile)

## Translated sections
- Landing: Hero, Features, HowItWorks, Stats, Testimonials, CTA
- Layout: PublicLayout nav + footer
- Keys organized by section: nav.*, hero.*, features.*, pricing.*, etc.

## RTL
- Arabic triggers `dir="rtl"` on `<html>`
- CSS adjustments in index.css for RTL gradient direction

## Adding new translations
1. Add keys to all 5 locale JSON files
2. Use `const { t } = useTranslation()` in components
3. Replace hardcoded text with `t("section.key")`
